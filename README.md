# SystemVerilog 代码阅读训练

这里不是“写完一题”的题库，而是短片段识读训练。每次只读 1 个片段，先在纸上或空白处写下判断，再展开参考分析。

## 固定动作

对每个片段回答：

1. 信号的位宽、符号和角色是什么？
2. 这是组合逻辑、时序逻辑，还是测试平台代码？
3. 在哪个时刻更新或检查？
4. 给定一个输入时，下一拍会发生什么？
5. 有什么常见误读或边界风险？

每批约 15 分钟。首次只做“代码 + 你的判断”；第二次才展开答案。不要一上来读参考分析。
